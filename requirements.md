# UniTime Project Requirements

## Project Description
UniTime is a university timetabling system used to create and manage course schedules, examination schedules, events, rooms, instructors, and student scheduling.

## Main Requirements
- Manage university course timetables
- Manage examination timetables
- Manage rooms and events
- Reduce student course conflicts
- Support multiple departments working on schedules
- Provide backend logic for scheduling and validation

## Maintenance Scope
In this project, we focus only on the Java backend. Our team will propose and implement maintenance changes such as bug fixes and backend feature improvements.
